## 1. First run (replace signup→dashboard)

```
WELCOME (language pick: EN/AR)
 → MEET AZOUZ (natural intro; Azouz speaks, voice-forward for 8–9)
 → CHILD IDENTITY (name/display, light)
 → AVATAR / HERO CREATION (cosmetics exist: AvatarCosmetic)
 → INTEREST DISCOVERY (feeds adaptation — Learner.preferences)
 → AGE / DEVELOPMENT CONTEXT (band; refined later by performance)
 → LIGHT DIAGNOSTIC (game-framed; sets starting mastery per domain — 07 §4)
 → LEARNING PROFILE (Azouz reflects back "here's your start")
 → FIRST PERSONALIZED WORLD (domain-scoped World, unlock-aware)
 → FIRST MISSION (guided; teach beat → practice)
 → FIRST SUCCESS (real evidence recorded)
 → FIRST MEANINGFUL REWARD (reward ≠ mastery; no manipulation — 06 R9)
 → NEXT RECOMMENDATION (always "what's next")
```
Never feels like a form; each step is in-world and Azouz-guided. Onboarding IS
the beginning of the learning adventure.

## 2. Self-directed operation (directive §27) — the product continuously answers

| Child question | Where answered |
|---|---|
| Where am I? | world map + breadcrumb + Azouz context |
| What am I doing? | mission stepper, current beat |
| Why? | objective framing ("you're learning to…") |
| What next? | recommendations + single clear next action |
| Can I get help? | Azouz / specialist mentor / hints (hints before answers) |
| What did I learn? | post-mission reflection + mastery change |
| What did I create? | portfolio artifact |
| What am I better at? | mastery-by-domain, balanced development |
| What happens next? | next recommendation / next stage node |

No screen leaves the child at a dead end (defect if it does — §34).

## 3. Return session

Azouz greets with context ("last time you…"); REVIEW surfaces due items (FSRS);
daily goal cadence (DailyGoal exists); one clear next action; streak encourages
(never shames). Specialist characters appear when educationally relevant, not as
popups.

## 4. Age-adaptive journey (07)

8–9: voice-forward, 1-level nav, short beats, heavy scaffold, protective tone.
10–11: more text, real projects, guided. 12–14: self-directed, deeper projects,
abstract/ethics, peer-mentor tone. Same journey skeleton, adapted density/length/
voice/scaffold via `useAgeAdaptation` + `AgeVariant`.

## 5. Azouz's role in the journey (23 / directive §31)

Welcomes, knows context, introduces missions, explains, asks, hints, encourages,
reflects, celebrates real progress, navigates the world, introduces specialists,
remembers appropriate history, adapts tone by age. NEVER: creates dependency,
asks secrecy, replaces parents, manipulates, pressures emotionally.

## 6. Acceptance (maps to 46)

The 7 child-truth checks (14 §3) must pass for a new 8/10/12/14-year-old walking
first-visit→return. Verified by observed browser QA (not assumed) — 46.
