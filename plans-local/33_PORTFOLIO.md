code, AI creations, pitches) + the Evidence behind them. Not just a project list
(the prior gap GAP-027). Shows "what I made" (child) + "what my child made"
(parent, 16).

## 2. Credentials (Open Badges)

`CredentialDefinition` → issued `Credential` on stage/competency mastery.
Verifiable (public verify page, 19). Open Badges standard (confirm exact lib —
36 §8 open item). Parent-facing recognition + a real willingness-to-pay lever
(48 §5). Export gated by `credentials`/`portfolioExport` entitlements (10).

## 3. Evidence linkage

Portfolio artifacts + credentials trace back to `Evidence` → `MasteryRecord` →
competency → domain. A parent can go from "credential" → "what it means" →
"the evidence". This traceability is the trust mechanism.
