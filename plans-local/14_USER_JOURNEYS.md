## 2. The learning session (the core repeated journey — 06 §3 / 31)

`REVIEW → DISCOVERY → EXPLANATION (teach beat) → PRACTICE → INTERACTION (character/
voice) → CREATION → REFLECTION`, adapting beats/length to age + mastery + interest
+ load + objective. Every session ends by answering "what's next?".

## 3. Acceptance bar per journey (directive §39, from North Star §34/§35)

**Child-truth:** can a new child, with no adult, (1) understand what to do,
(2) navigate + recover from confusion, (3) see progress, (4) choose meaningfully,
(5) interact with AI safely, (6) create something, (7) always know what's next?
**Parent-truth:** can a parent see (1) what the child learns, (2) what they made,
(3) how progress is measured, (4) that it's safe, (5) that price maps to outcomes?

A journey that feels confusing, empty, fake, unfinished, overly childish, too
hard, too static, or like a generic LMS = NOT DONE (directive §39). These are the
tests in 46_FINAL_ACCEPTANCE.
